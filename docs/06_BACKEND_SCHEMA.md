# Backend Schema

## Scope And Confidence

This is the candidate final state obtained by applying the checked-in SQL sources in numeric phase order, including both phase-3 and phase-24 files, the dated phase-25 file, and the phase34 review migration. It is not a live database dump. The phase30, phase32, and phase34 files contain review-only/do-not-run comments; deployment status for these and all manually managed migrations is **TO CONFIRM**. Sources: [schema.sql](../../mobile-app/mobile-app/supabase/schema.sql), [phase30_security_audit_hardening.sql](../../mobile-app/mobile-app/supabase/phase30_security_audit_hardening.sql), [phase32_kyc_docs_column_and_refunds.sql](../../mobile-app/mobile-app/supabase/phase32_kyc_docs_column_and_refunds.sql), [phase34_product_reapproval.sql](../../mobile-app/mobile-app/supabase/phase34_product_reapproval.sql).

`seed.sql` inserts demo categories, products, and product images; it defines no schema objects. Source: [seed.sql](../../mobile-app/mobile-app/supabase/seed.sql).

`NOT NULL`, defaults, foreign keys, and checks below are stated only where declared by the SQL sources. For exact live state, run [_verify.sql](_verify.sql) in the Supabase SQL Editor and compare its results; policy/function grants can differ from the source files. Sources: [schema.sql](../../mobile-app/mobile-app/supabase/schema.sql), [phase34_product_reapproval.sql](../../mobile-app/mobile-app/supabase/phase34_product_reapproval.sql).
